# Security policy

Homepage Config can read and change every credential in a Homepage configuration, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via GitHub: **Security → Report a vulnerability** on https://github.com/ckegels/homepage-config.

Include the version, the install method (LXC installer or Docker), and steps to reproduce. You'll get an answer as soon as possible.

## Supported versions

Only the latest release receives fixes.
